# Talking-Head Prompt Contract (Phase B)

Write one video prompt per approved clip. Do not start until Phase A is approved.

Each prompt:

1. Duration in this clip's own seconds, aspect ratio, the character speaking that clip's line to the lens. Shot size follows the director visual.
2. First frame = this clip's start still. Last frame = this clip's end still. For clip 2 and after, the first frame is the previous clip's last frame.
3. Motion: continuous lip-sync like a real person filming a phone video at home. The character stays seated. Eyes locked on the lens. Head tilting and nodding. Shoulders rocking. One hand keeps a small homemade microphone — a thin stick with a fluffy fuzzy windscreen — near the mouth, and that hand does not swap. Camera stays on the same framing from the first frame to the last: no cut, no zoom, no jump. Never freeze the face, head, or the mic hand. Never stand up.
4. The subtitle is LARGE. It fades and slides in over the first 0.4s, holds still through the line, then fades and slides out over the last 0.5s. On 9:16 it sits a little below the vertical center. On 16:9 it sits across the bottom.
5. No background music. No extra writing.
