# Opening Clip Prompt Contract (Phase B)

Use only after explicit approval of the current Phase A. Write ONE self-contained video prompt.

## Prompt order

1. Output spec: duration in seconds (3–4), aspect ratio, synchronized audio.
2. Style lock: the canvas, look and negatives from the Visual style block in one sentence.
3. Logo lock: the logo follows the START and END keyframes exactly — same shapes, colours, lettering. Never redraw or morph it into a different mark.
4. Scene at t=0: the logo state in the START keyframe (hidden / small / forming).
5. The one reveal move, timed across the full duration, landing on the END keyframe.
6. Camera: still or one gentle push-in. No cuts.
7. Audio: the short line quoted exactly once, or silence; one reveal SFX; no background music.
8. Handoff: the logo at rest, centered, for the main video to cut in.
9. Negatives: no extra text, no wrong spelling, no logo distortion, no style drift.

## Dual-keyframe rule

Start and end keyframes are the SAME SHOT. Interpolate across the full duration; never hold the start and snap to the end in the last frames.
