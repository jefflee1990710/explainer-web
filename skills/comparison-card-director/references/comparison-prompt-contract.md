# Comparison Card Clip Prompt Contract (Phase B)

One prompt per approved clip.

1. Duration 3–8 seconds, aspect ratio, the split (left/right or top/bottom).
2. Style lock from the Visual style block.
3. Both panel titles spelled exactly from `narrativeJob`. They are the only writing.
4. Scene at t=0: both halves already visible.
5. Timed beats: one half changes, then the other. The divider stays. No cut to a single picture.
6. Narrator line quoted once as audio. No voiceover caption.
7. Last clip rests on both halves. No loop.

Colours in ordinary words only.
