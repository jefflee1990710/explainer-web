# Follow Shot Prompt Contract (Phase B)

Write one video prompt per approved clip. Do not start until Phase A is approved.

Each prompt:

1. Duration in this clip's own seconds (3–6), aspect ratio, third-person, locked camera.
2. First frame = this clip's start still. Last frame = this clip's end still. From clip 2 on, the first frame is the previous clip's last frame.
3. One beat: a few steps, a turn, or one gesture. The character stays a similar size. The background shifts only a little.
4. Clothes stay as in the frames. No new angle and no cut.
5. The last clip ends with the character stopped.
6. One footstep or room sound. No narrator. No subtitle when `englishVo` is `(no dialogue)`.
