# Talking-Head B-roll Clip Prompt Contract (Phase B)

One prompt per approved clip.

1. Duration 3–8 seconds and aspect ratio.
2. Style lock from the Visual style block.
3. If `narrativeJob` is `on-camera`: the attached character, medium close-up, eyes to the lens, the locked background. They speak the line once.
4. If `narrativeJob` is `b-roll`: no character. Show the subject. Quote an off-screen line once, or state no dialogue.
5. Timed beats inside the shot. Name the cut at the boundary: from the face, or back to the face.
6. No background music.
7. The last prompt rests on the face. No loop.

Colours in ordinary words only. Do not restyle the character.
