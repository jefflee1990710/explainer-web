# Talking-Head Prompt Contract (Phase B)

Write one video prompt per approved clip. Do not start until Phase A is approved.

Each prompt:

1. Duration in this clip's own seconds, aspect ratio, locked full-body, the character speaking that clip's line to the lens. Head, torso, and feet stay in frame.
2. First frame = this clip's start still. Last frame = this clip's end still. For clip 2 and after, the first frame is the previous clip's last frame.
3. Motion: mouth, a small nod, and natural body gestures. Feet stay in frame. Camera locked. No cut.
4. Bottom subtitle stays that clip's spoken line for the whole clip.
5. No background music. No extra writing.
