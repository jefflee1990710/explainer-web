# 影片編輯器 UX 重新設計

日期：2026-09-27
狀態：待使用者審閱

## 目標

讓使用者在影片編輯器（`video-editor-dialog.tsx`）裡更容易產生與修改影片。解決四個痛點：

1. 不知道下一步（畫格 → 影片）。
2. 不知道怎麼改（改文字、標註、重畫入口太多）。
3. 一段一段做太慢，需要批次。
4. 看不出整支影片進度與哪些段落未完成。

## 範圍

- 維持現有 Studio 版面：左欄表單 300px、右側預覽、底部膠卷（`StudioFrame` / `Filmstrip`）。
- 不改後端產生流程與計價（`FRAMES_COST=2`、`FRAME_COST=1`、`VIDEO_COST=1`）。
- 新增一個「選取段落批次」server action，其餘重用現有 action。

## 第一段：版面與「下一步」主按鈕

### 頂列（header）

- 左：影片標題。
- 中：進度摘要「畫格 x/n · 影片 y/n」，點擊跳到第一段未完成的 clip。
- 右：「全部產生」、「下一步：成片」、「⋯」選單。
- 「⋯」選單：刪除影片、顯示技術資訊（切換產圖 Prompt 除錯面板）、關閉。

### 左欄

由上到下：

1. 片段標題 `Clip{n}.mp4 · 起–訖時間`。
2. 主按鈕區（固定在頂部，sticky）。
3. 修改表單（見第二段）。

### 主按鈕：每段只有一顆，依階段變化

| 階段 | 主按鈕 | 輔助文字 |
|---|---|---|
| `no_frames` | 畫這段畫格 · 2 | 先畫起始與結束兩張 |
| `frames_generating` / `video_generating` | 停用＋轉圈 | 約 30 秒 |
| `frames_ready` | 產這段影片 · 1 | 滿意畫格就產片 |
| `video_ready` | 下一段 → | 跳到下一段未完成 clip |
| `frames_failed` / `video_failed` | 重試 · 對應 credits | 顯示失敗原因 |
| 需重做（stale） | 重畫畫格 · 2 或 重產影片 · 1 | 說明哪部分過期 |

- 次要動作以一排小字連結放在主按鈕下（例：「只重畫起始畫格」）。
- 主按鈕的決定邏輯抽成純函式（如 `clipNextAction(state)`），附單元測試。

### 右側預覽

- 保留起始畫格 → 箭頭 → 結束畫格。
- 沒有影片時移除大虛線框，改成一行提示「產片後會在這裡播放」。
- 有影片才顯示播放器。
- 產圖 Prompt 除錯面板預設隱藏，由「⋯ → 顯示技術資訊」開啟。

## 第二段：修改流程

### 表單分區

1. 旁白（預設展開）：`startVo`「開頭旁白」、`endVo`「結尾旁白」。
2. 畫面（預設收合）：`startScene`「起始畫面描述」、`endScene`「結束畫面描述」。收合時顯示一行摘要。
3. 鏡頭（預設收合）：`motionCamera`「鏡頭動作」，只影響影片。

### 儲存列

- 有改動才出現，固定在表單底部。
- 兩顆按鈕：「儲存」與「儲存並重畫 · 2」。
- 實作時修正：畫面文字永遠開啟（`resolveSceneText` 固定 `enabled: true`，旁白會寫進畫格），鏡頭動作也寫進畫格 prompt。因此任何文字修改都會讓畫格與影片過期，不做「只重產影片」的分類。

### 重畫入口：從四個變兩個

1. 改文字 → 儲存列。
2. 點預覽中的畫格 → 開啟現有 `FrameEditDialog`（標註＋備註）→「重畫這張 · 1」。滑鼠移上時提示「點擊標註修改」。

移除畫格下方的「重畫 · 1」、「兩張重畫 · 2」按鈕，以及 `ClipScenePrompts` 內的「儲存並重畫兩張 · 2」。

## 第三段：批次與整體進度

### 頂列「全部產生」

沿用 `bulk-generate-dialog.tsx`，改成 Studio 淺色樣式並加上模式選擇：

- 補完未完成（預設）→ `generateRemainingAction`。只處理未畫格、失敗或需重做的段落。
- 只畫畫格 → `generateAllSceneImagesAction`，標示「會覆蓋已完成段落」。
- 畫格＋影片 → `generateAllClipsAction`，標示「會覆蓋已完成段落」；影片 credits 在畫格完成後才扣。

視窗列出段落編號、每項 credits 算式、合計與剩餘。credits 不足時停用確認並附升級連結。

### 膠卷多選

- 每段縮圖左上角有核取方塊，hover 時出現；只要有一段被勾選，全部顯示。
- 點縮圖＝選取編輯；勾選方塊＝加入批次，兩者分開。
- 有勾選時膠卷上方浮出操作列：「已選 n 段」、「畫格 · 2n」、「產片 · m」、「取消」。
- 「產片」只計畫格已完成的段落，其餘顯示略過原因（例：「2 段可產片，1 段缺畫格」）。
- 新增 server action（例：`generateSelectedClipsAction(projectId, clipIds, kind)`），重用單段畫格／影片服務，一次檢查 credits。

### 進度顯示

- 膠卷每段底部 3px 色帶：灰＝未開始、青（閃動）＝產生中、綠＝影片完成、紅＝失敗、橘＝需重做。
- 頂列進度摘要（見第一段）。
- 全部影片完成前，「下一步：成片」停用，提示「還有 k 段未產片」。

## 元件拆分（預計）

- `clip-next-action.ts`（純函式＋測試）
- `clip-primary-action.tsx`（主按鈕區）
- `clip-scene-prompts.tsx` 就地改成分區表單＋儲存列
- `production-toolbar.tsx`（編輯區頂部工具列：進度摘要、全部產生、技術資訊開關；放在編輯器內而非對話框標題列，狀態才能留在製作元件內）
- `filmstrip-selection-bar.tsx`（多選操作列）
- `Filmstrip` 增加 `checkedIds` / `onToggleCheck` / 狀態色帶
- `bulk-generate-dialog.tsx` 改樣式並加模式選擇

## 驗證

- 純函式單元測試：`npx tsx --test`。
- 瀏覽器實測：各階段主按鈕、儲存列行為、點畫格標註、全部產生視窗、膠卷多選、進度色帶、窄螢幕。
