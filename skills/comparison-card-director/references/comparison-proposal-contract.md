# Comparison Card Proposal Contract (Phase A)

## Header

1. Titles in the reference language and in English
2. Duration, clip count, loop mode: always Linear
3. The contrast in one sentence, and which side is panel A
4. Aspect ratio and the split (left/right or top/bottom)
5. Narrator voice
6. Cast lock if a host is attached; otherwise say there is no host

## Storyboard

Each row is one split. `narrativeJob` is `contrast: <panel A title> | <panel B title>`.

`explainerScene` describes both pictures and where the host stands, if any. Do not repeat the title wording inside the scene; the titles are taken from `narrativeJob`.

`motionCamera` is timed beats inside the same split: one half changes, then the other, camera stays locked. No cut to a single full-frame shot.

## Counts

- **4–8s micro**: 1–2 clips
- **15–20s**: 2–4 clips
- **30–45s**: 4–6 clips
- **50–60s**: 6–8 clips

The last clip rests. Both halves stay visible.
