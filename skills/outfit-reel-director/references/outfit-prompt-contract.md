# Outfit Reel Prompt Contract (Phase B)

Write one video prompt per approved clip. Do not start until Phase A is approved.

Each prompt:

1. Duration 3–4 seconds, aspect ratio, full-body, locked on THIS clip's camera angle.
2. First frame = this clip's start still. Last frame = this clip's end still. Same camera inside the clip. From clip 2 on, clothes continue but the angle is new — do not copy the previous facing-forward stance.
3. Name the one new garment and the hand that puts it on. Write real body motion (weight shift, look down, 3/4 turn, arms into sleeves, or a step), not hands-only while she stands frozen. If it replaces the white knee-length athletic shorts, those shorts are off in the last frame. Other garments already on stay on. Never pull a top over the head. Never pull a bottom up from the thighs. The new bottom is already at the natural waist; the previous shorts vanish underneath; the torso stays covered.
4. Face, hair, and body proportions stay as in the frames. Do not copy a person from a clothing photo.
5. The hold clip adds no garment. The look rests.
6. One clothing sound effect on a dressing clip. No spoken line unless the approved `englishVo` is a real line.
7. No subtitles on a `(no dialogue)` clip. No step numbers.
