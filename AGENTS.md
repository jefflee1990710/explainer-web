## Commands

- **Dev / Build**: `npm run dev` (`next dev --webpack`), `npm run build` (`next build --webpack`). Webpack is required (not Turbopack) for synchronous WebAssembly (`opencut-wasm`) and module aliases in `next.config.ts`.
- **Lint**: `npx eslint src/` or `npx eslint src/path/to/file.ts` (ESLint 9; ignores `opencut/**` and `src/opencut/**`). Avoid bare `npm run lint` when `.worktrees/` or `experiments/**/.venv/` exist locally, as scanning them can time out.
- **Typecheck**: `npx tsc --noEmit` (path alias `@/*` resolves to `./src/*`; excludes `opencut/`).
- **Tests**: Uses Node's built-in test runner (`node:test` + `node:assert/strict`) executed via `tsx`:
  - Single test file: `npx tsx --test src/path/to/file.test.ts`
  - Service unit tests: `npx tsx --test 'src/service/**/*.test.ts'`
  - All unit tests: `npx tsx --test 'src/**/*.test.ts'`
- **Scripts**: CLI scripts in `scripts/*.ts` call `loadEnvConfig(process.cwd())` from `@next/env` and run via `npx tsx scripts/<name>.ts` (see `package.json` for `seed:*`, `backfill:profiles`, and `migrate:folders`).

## Architecture & Conventions

- **Layering (`src/`)**:
  - `src/app/` — Next.js App Router pages and thin route entrypoints. Route handlers in `src/app/api/**/route.ts` only set `runtime` / `dynamic` and re-export handlers from `src/presentation/api/**`.
  - `src/presentation/` — Server Actions (`actions/*.ts`, `"use server"` wrappers delegating to `src/service/`), API route implementations (`api/`), studio shell (`studio/`, styled via `src/presentation/studio/tokens.css`), UI components (`components/`), and public DTO serializers (`serialize.ts`).
  - `src/service/` — Domain and business logic (AI storyboard director on Google Gemini, OpenRouter image/video generation queue, FFmpeg reel assembly & video editing, billing/credits, Firebase auth, MCP server).
  - `src/dao/` — MongoDB collection accessors (`getDb()` singleton in `src/dao/mongo.ts`). Always import collections from `@/dao`.
  - `src/model/` — TypeScript types and Zod schemas.
- **Naming Trap — Folders vs. Videos**:
  - A **Folder** (project container) uses model `Folder` (`src/model/folder.ts`) and is stored in the **`projects`** MongoDB collection (`projectsCollection()` in `src/dao/projects.ts`).
  - A **Video** (AI Influencer / explainer job) uses model `Project` (`src/model/project.ts`, with `projectId` pointing to its parent `Folder._id`) and is stored in the **`videos`** MongoDB collection (`videosCollection()` in `src/dao/videos.ts`).
- **Auth & Legacy Naming (`clerkUserId`)**:
  - Auth uses **Firebase Auth** (`firebase` / `firebase-admin`), **not Clerk**.
  - User and resource documents still store the Firebase `uid` in the field named `clerkUserId` (and helpers like `requireClerkUserId()` in `src/service/auth.ts` return the Firebase `uid`) for backward compatibility with existing MongoDB documents and indexes.
  - Web requests authenticate via the Firebase session cookie (`src/proxy.ts` — Next.js 16 proxy convention replacing `middleware.ts`).
  - REST API (`/api/v1/*`) and `/api/mcp` authenticate via `Authorization: Bearer <token>`, accepting either a Firebase ID token or an `exp_live_*` MCP API key (`src/service/api/auth.ts`), and bind the user via `AsyncLocalStorage` so `requireAppUser()` works unchanged across Server Actions and API routes.
- **Vendored OpenCut**:
  - `opencut/` (upstream reference checkout) and `src/opencut/` (vendored client editor code) are excluded from ESLint (`eslint.config.mjs`), and `opencut/` is excluded from `tsconfig.json`. The Scro ↔ OpenCut bridge lives in `src/opencut/embed/` and `src/service/opencut/`.
- **Generation Queue & Providers (`OPENROUTER_API_KEY`)**:
  - Long-running image/video jobs are persisted in `generation_jobs` (`generationJobsCollection()`), kicked off via `after()` (`runJobById`), and settled by `persistImmediateSubmit` (sync image jobs) or the minute crons `/api/cron/submit-jobs` and `/api/cron/refresh-jobs` (`src/service/generation/task-runner.ts`).
  - **Images** (`src/service/generation/image-backend.ts` → `src/service/openrouter/generate.ts`): All image generation across the entire system (scene frames, locks, covers, life photos, character boards, and pose edits) uses `bytedance-seed/seedream-5-0-pro` through OpenRouter `POST /api/v1/images` (`bytedance-seed/seedream-5-0-lite` remains available; up to 14 references, 1K/2K). Responses are synchronous base64 data URLs uploaded to Vercel Blob (`persistMedia`). Never store raw multi-MB `data:` URLs in MongoDB `outputUrl` fields.
  - **Videos** (`src/service/generation/video-backend.ts` & `src/service/higgsfield/clip-keyframes.ts` → `src/service/openrouter/generate.ts`):
    - **Voice-First Pipeline (`ElevenLabs -> Audio -> Video`)**: All voiced clips across all languages (`yue`, `en`, `zh`, etc.) pre-synthesize `.mp3` speech via ElevenLabs `eleven_v4` (`resolveVoiceSwapId` in `src/service/voice/voice-swap-target.ts`) before video submission. Silent clips (`(no dialogue)` / outfit directors) skip TTS and preserve native model SFX.
    - `talking-head-director` (up to `120s` per clip) is the ONLY director that runs on OpenRouter `heygen/avatar-iv` (`$0.05/s`, `input_references: [image_url, audio_url]`), followed by `trimClipSmoothSilence` and `gradeTalkingHeadSensorTextureBuffer` (`full-body-talking-head-director` and `surprise-interview-director` are hidden from the picker via `hiddenInPicker: true`).
    - All other directors run 1 pass on OpenRouter `POST /api/v1/videos` with `frame_images` (`first_frame` / `last_frame`) and `generate_audio: true`, then mux the pre-generated ElevenLabs `.mp3` track via `swapClipVoice`: Story directors (`story-short-director` and `one-take-director`) and `realistic` styles use `minimax/hailuo-3` (`2K`, 7,000-char prompt limit enforced by `capOpenRouterVideoPrompt`, billed at 15 credits/s); non-realistic non-story styles use `alibaba/wan-3.0` (`480p`, `$0.05/s`, billed at 9 credits/s). When `OPENROUTER_WEBHOOK_SECRET` is set and the app URL is public HTTPS, submit includes `callback_url` pointing at `POST /api/webhooks/openrouter` (HMAC `X-OpenRouter-Signature`). Status polling through `fetchOpenRouterStatus` (`GET /api/v1/videos/{id}`) remains the fallback.
    - **Scro Swap** (`/app/scroswap` & OpenEdit clip inspector): when `COMFY_BASE_URL` and `COMFY_API_KEY` are set, character swap submits the OpenJutsu `simple` workflow and object swap submits `object` (masked H3 on the self-hosted ComfyUI; still images, relight, and color fix stay on the cloud path below). Otherwise, grey-mannequin motion masks prefer fal `fal-ai/sam-3/video-rle` when `FAL_KEY` is set (pixel RLE → grey silhouette); otherwise OpenRouter VLM bbox ellipses. When a mannequin video exists and `MINIMAX_API_KEY` is set, render uses official MiniMax Video V2 `MiniMax-H3` reference-to-video (`reference_image` = prepared start still, plus the original character photo as a second `reference_image` for Character Motion Swap; `reference_video` = mannequin; `reference_audio` = extracted section `.mp3` when source audio exists and `noLipSync` is off; `2K`). That request must not also send `first_frame` / `last_frame`. Otherwise it falls back to OpenRouter `minimax/hailuo-3` with start and end frames. When started from a completed clip inside the OpenCut editor (`src/service/opencut/clip-jutsu.ts`), completion replaces that clip in `videos.clips` (`settleTargetClipFromEngineJob`) and updates the timeline in place.
    - **Teleport** (`/app/teleport` & OpenEdit clip inspector): when `COMFY_BASE_URL` and `COMFY_API_KEY` are set, render submits the OpenJutsu `object` workflow with `mode: background`. Otherwise it relocates the original person into a new scene. A scene photo is the place and optional text only changes mood; text alone first generates an empty Seedream 5.0 Pro scene plate. Identity is a SAM cutout of the start frame on a plain background, or the raw start frame when that mask is missing. Motion uses the same grey mannequin as Scro Swap (`768px`). With a mannequin and `MINIMAX_API_KEY`, render is MiniMax H3 reference-to-video (`reference_image` 1 = relocated start, `reference_image` 2 = identity, `reference_video` = mannequin, `reference_audio` = extracted section `.mp3` when `keepSourceAudio` is on, `2K`, no `first_frame` / `last_frame`). Otherwise OpenRouter `minimax/hailuo-3` uses the relocated start and end frames. Output is `9:16` on `/app/teleport` and matches `project.aspectRatio` when triggered on a completed clip inside OpenEdit (`src/service/opencut/clip-jutsu.ts`).
    - **Extend Video** (OpenEdit clip inspector → `Clip N+1`): when `COMFY_BASE_URL` and `COMFY_API_KEY` are set, extending a completed clip (`src/service/opencut/clip-jutsu.ts` → `src/service/extend/pipeline.ts`) immediately inserts a new `Clip N+1` after `Clip N` via `insertClips` and submits the OpenJutsu `extend` workflow (`src/service/comfy/workflows/extend.api.json`), encoding the last 39 frames of `Clip N` as a protected target latent prefix (`MiniMaxH3ChainExternalVideo` with `prepend_original: false` + `MiniMaxH3ChainContext` Soft AV), feeding the last 6s video + auto-resolved Character/Scene/Props reference images into `MiniMaxH3ReferenceToVideo`, and trimming the 39-frame overlap (`MiniMaxH3LoopTrim`) so only the new ~6s segment settles into `Clip N+1`. Standard storyboard clip generation can also optionally route `minimax/hailuo-3` clips to Vast `ref2va` when `COMFY_CLIP_VIDEO_ENABLED=true` (`src/service/comfy/submit-clip-video.ts`).
  - **Model & Pipeline Reference (`pipeline-models.md`)**: Whenever any LLM, image, video, TTS/alignment model, resolution, or director pipeline changes, update `pipeline-models.md` so it stays in sync with the system design.
  - **Director Prompt Isolation (`1 Director = 1 File` in `src/service/director/rules/<director-slug>.ts`)**: Every director has its own standalone rule file (`1 Director = 1 File`). NEVER share generic prompt blocks across directors—always duplicate rules inside each director's dedicated file so editing one director never affects any other director. Whenever future AI updates modify a director's behavior or prompt rules, modify ONLY that specific director's file individually.
  - **Testing Rule**: Never make live paid provider calls during unit tests; use pure functions or mock `fetch` (`{ fetch: fakeFetch }`).
